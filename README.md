# examples

Runnable examples for the t-rust-db family of products.

- [`column-rs/`](column-rs/) — SQL-over-Parquet queries against column-rs: filter, group-by, order-by/limit, join, window function.
- [`sqlite-rs/`](sqlite-rs/) — a multi-table SQLite database against sqlite-rs: Quentin Tarantino's and the Coen Brothers' filmographies and their lead cast, joined across four tables.
